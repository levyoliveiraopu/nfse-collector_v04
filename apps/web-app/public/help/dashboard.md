## Para que serve

O Dashboard resume a situação da operação. Use-o para descobrir rapidamente se há empresas sem credencial válida, coletas em andamento, falhas ou ocorrências abertas.

## Como usar

1. Confira os indicadores do período atual.
2. Priorize cartões de alerta ou erro.
3. Abra a seção relacionada no menu para investigar.
4. Volte ao Dashboard depois do tratamento para confirmar a atualização.

## Regras e status

- Indicadores são resumos; o detalhe da empresa ou execução é a fonte para investigação.
- Uma execução parcial terminou, mas possui itens que precisam de conferência.
- Valores podem mudar enquanto workers e agendamentos estão processando.

## Se algo não aparecer

Atualize a página. Se o problema continuar, confira Execuções e Ocorrências. Escale ao administrador quando todo o painel estiver sem dados ou indisponível.
