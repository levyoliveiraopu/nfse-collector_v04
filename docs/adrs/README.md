## Como escrever um novo ADR

1. Copie um arquivo existente como base.
2. Numero sequencial: `NNNN-slug-curto.md`.
3. Status: `Proposto` -> `Aceito` / `Rejeitado` / `Substituido por ADR-NNNN`.
4. Atualize este indice.
