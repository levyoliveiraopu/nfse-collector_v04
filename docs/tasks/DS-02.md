# DS-02 — Design tokens + tema base

- **Trilha:** ds
- **Tamanho:** M
- **Status:** blocked (aguarda DS-01)
- **Depende de:** DS-01

## Objetivo

Sistema de tokens (cores, tipografia, espacamento, radius, sombras) em
CSS vars + extensao do Tailwind.

## Entregaveis

- `apps/web-app/styles/tokens.css` com CSS vars (light + dark).
- `tailwind.config.ts` mapeando tokens para cores/fontes.
- Paleta: neutra + 1 primaria (azul corporativo) + 1 critica (vermelho).
- Fontes: Inter (ui) + JetBrains Mono (codigo).
- Pagina `/_styleguide` lista amostras dos tokens.

## Definition of Done

- [ ] Light/dark toggle funciona (classe `dark`).
- [ ] Styleguide renderiza todos os tokens.
