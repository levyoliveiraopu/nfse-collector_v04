# DS-03 — Layout shell (Sidebar + Topbar + breadcrumbs)

- **Trilha:** ds
- **Tamanho:** M
- **Status:** blocked (aguarda DS-02)
- **Depende de:** DS-02

## Objetivo

Shell reutilizavel para todas as paginas logadas.

## Entregaveis

- `<AppShell>` com sidebar colapsavel (256px/64px) e topbar fixa.
- Sidebar com navegacao principal (placeholders).
- Topbar: breadcrumbs, seletor de tenant (dropdown, futuro), bell de
  notificacoes (placeholder), menu do usuario.
- Rota `/dashboard` usando o shell.
- Acessibilidade: foco visivel, landmarks ARIA.

## Definition of Done

- [ ] Shell responsivo (colapsa < 1024px).
- [ ] Lighthouse acessibilidade >= 95 na pagina exemplo.
