# DS-04 — Componente StatusBadge (10 variantes)

- **Trilha:** ds
- **Tamanho:** S
- **Status:** blocked (aguarda DS-02)
- **Depende de:** DS-02

## Objetivo

Badge reutilizavel para status de execucoes, credenciais e ocorrencias.

## Entregaveis

- `<StatusBadge variant="..." />` com variantes:
  `success`, `processing`, `pending`, `failed`, `warning`, `blocked`,
  `cert_expiring`, `cred_invalid`, `portal_unstable`, `reprocess_needed`.
- Cada variante com icone (Lucide) + cor + tooltip.
- Tamanhos: sm, md.
