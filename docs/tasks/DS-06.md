# DS-06 — Componente DataTable (server-side)

- **Trilha:** ds
- **Tamanho:** L
- **Status:** blocked (aguarda DS-02)
- **Depende de:** DS-02

## Objetivo

Tabela reutilizavel com paginacao e filtragem server-side, usada em
empresas, execucoes, itens, arquivos, usuarios.

## Entregaveis

- `<DataTable columns data fetch onFilterChange />` baseado em
  TanStack Table + uso via react-query.
- Filtros: texto, select, date-range, saved filters (localstorage).
- Paginacao: offset + page-size.
- Ordenacao server-side.
- Estados: loading skeleton, vazio, erro com retry.
- Export CSV do resultado atual.

## Definition of Done

- [ ] Exemplo com 10k linhas mockadas funciona fluidamente.
- [ ] Filtros preservam na URL (searchParams).
