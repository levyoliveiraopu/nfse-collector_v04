# DS-09 — Cliente API tipado (gerado do OpenAPI)

- **Trilha:** ds
- **Tamanho:** M
- **Status:** blocked (aguarda DS-01 + API-01)
- **Depende de:** DS-01, API-01

## Objetivo

Cliente TypeScript autogerado do OpenAPI da API, com interceptor de
auth (injeta JWT, renova com refresh) e react-query hooks.

## Entregaveis

- `packages/api-client/` (ou `apps/web-app/lib/api/`).
- Gerador: `openapi-typescript` (tipos) + `openapi-fetch` (client leve).
- Script `pnpm --filter web-app generate-api` baixa OpenAPI de
  staging/local e regenera tipos.
- Interceptor: erro 401 dispara refresh; falha -> redirect /login.
- Hooks react-query base: `useMe`, `useCompanies`, `useExecutions`, etc.

## Definition of Done

- [ ] Tipagem compila; chamada real de `/health` funciona.
- [ ] Re-run do script e idempotente.
