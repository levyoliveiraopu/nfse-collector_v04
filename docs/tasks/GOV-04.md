# GOV-04 — Criar STATE.md e regras de atualizacao

- **Trilha:** governance
- **Tamanho:** S
- **Status:** completed (entregue neste PR de setup)
- **Depende de:** GOV-01

## Objetivo

Criar arquivo `STATE.md` como fonte unica de verdade do estado do
projeto, com regra de atualizacao obrigatoria em toda PR.

## Entregaveis

- `STATE.md` com secoes: Decisoes, Em Andamento, Proximas Destravadas,
  Bloqueadas, Limite de WIP, Pendencias, Ultima Atualizacao.
- Checkbox no PR template exigindo atualizacao.

## Definition of Done

- [x] STATE.md commitado.
- [x] PR template exige atualizacao.
